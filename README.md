# Abdulaziz Al shihry - CV Website

Professional CV website built with React, TypeScript, and Tailwind CSS.

## 🚀 Live Site

Visit: [https://abdulaziz-alshihry.github.io](https://abdulaziz-alshihry.github.io)

## 📋 Features

- Modern, responsive design
- Smooth scrolling navigation
- Professional sections: About, Skills, Experience, Education, Courses
- Mobile-friendly interface
- Easy to update and maintain

## 🛠️ Technologies

- React 18
- TypeScript
- Tailwind CSS
- Vite
- Lucide Icons

## 📦 Local Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```

## 📝 How to Update Your CV

Edit the `initialCVData` object in `/src/app/components/CVWebsite.tsx` to update:
- Personal information
- Summary
- Skills
- Experience
- Education
- Courses
